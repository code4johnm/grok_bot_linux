## Why this is not packaged further

This tree installs the existing Grok Bot desktop and Grok CLI. The desktop UI and the CLI already exist. A second web dashboard would invent a wrapper around those installers. This packaging does not add one and does not run an installer. Stop here. This is not an authorization to operate.
